Mit dem GitHub-Konto anmelden, das Schreibrechte auf pkphysio hat.

Stattdessen mit Token anmelden
  1. Auf GitHub: Profilbild oben rechts → Settings → Developer settings
  2. Personal access tokens → Fine-grained tokens → Generate new token
  3. Bei „Repository access“ → Only select repositories → pkphysio
  4. Bei „Permissions“ → Contents → Read and write
  5. Token generieren, kopieren und oben einfügen

Die Anmeldung bleibt nur in diesem Browser-Tab gespeichert. Nach dem Schließen des Tabs ist sie weg.
