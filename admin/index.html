Anmelden

Melde dich mit einem GitHub-Zugriffstoken an, um auf den Admin-Bereich zuzugreifen.

Wie bekomme ich ein Token?
  1. Auf GitHub: Einstellungen (oben rechts beim Profilbild) → Settings
  2. Ganz unten links: Developer settings
  3. Personal access tokens → Fine-grained tokens → Generate new token
  4. Bei "Repository access" → Only select repositories → pkphysio auswählen
  5. Bei "Permissions" → Contents → auf Read and write stellen
  6. Token generieren, kopieren und hier oben einfügen

Das Token wird nur in diesem Browser-Tab gespeichert und nie irgendwo hochgeladen. Nach dem Schließen des Tabs ist es weg.
